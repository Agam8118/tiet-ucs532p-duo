§4 — Proposed Methodology

Pipeline Design & Feature Strategy

A 5-stage classical CV + SVM pipeline for binary scratch detection — validated at 98% accuracy on 314 self-collected and NEU dataset images.

FIG. 1

Full Pipeline Overview

4.1

Camera Setup

A fixed overhead RGB camera is positioned above the inspection surface. Images are captured under workshop lighting without specialised hardware — any standard USB or webcam suffices.

01

Fixed Overhead Mount

Consistent viewpoint across all captures — minimises perspective distortion and scale variation between samples.

02

Dataset

314 total samples — 74 Good (Class 0) self-collected and 240 Scratch (Class 1) from the NEU Surface Defect Dataset. Images resized to 200×200 px during preprocessing.

4.2

Image Preprocessing

All images pass through a fixed, locked preprocessing chain before any feature computation. Parameters are frozen to ensure reproducible inference.

01

Grayscale Conversion & Resize

Convert RGB to single-channel grayscale via luminosity weighting. Resize to a fixed 200×200 px so feature computations are scale-invariant.

02

Median Blur (kernel = 5)

A 5×5 median filter suppresses salt-and-pepper noise — common in workshop-captured metal images — while preserving edge sharpness better than Gaussian blur for impulsive noise profiles.

Median Filter
I_out(x,y) = median { I(x+i, y+j) | i,j ∈ [-2,2] }
Window is 5×5 (kernel=5). No weighted average — replaces each pixel with the median of its neighbourhood.

# Locked preprocessing — DO NOT modify thresholds
img = cv2.imread(path, cv2.IMREAD_GRAYSCALE)
img = cv2.resize(img, (200, 200))
img = cv2.medianBlur(img, 5)                         # kernel=5
edges = cv2.Canny(img, 10, 70)                        # LOW=10, HIGH=70
kernel = np.ones((3,3), np.uint8)
dilated = cv2.dilate(edges, kernel, iterations=1)    # (3,3) kernel
4.3

Segmentation — Canny Edge Detection

Scratches appear as elongated intensity discontinuities. The Canny operator detects these high-gradient boundaries; dilation bridges small gaps to form connected scratch edges.

Canny Edge Detection — 4 stages
1. Gaussian smoothing: G(x,y) = (1/2πσ²) · exp(-(x²+y²)/2σ²) 2. Gradient magnitude: |∇I| = √(Gx² + Gy²) Gradient direction: θ = arctan(Gy / Gx) 3. Non-maximum suppression: keep pixel (x,y) only if |∇I(x,y)| is local maximum along θ direction 4. Hysteresis thresholding: strong edge → |∇I| ≥ T_high = 70 weak edge → T_low ≤ |∇I| < T_high (T_low = 10) discard → |∇I| < T_low = 10 weak edge survives only if connected to a strong edge
Low threshold T=10 ensures faint scratches are tracked. High threshold T=70 anchors confident edges. Ratio 1:7 is tighter than the common 1:3 — intentional to reduce false edges on rough steel texture.
Morphological Dilation
(A ⊕ B)(x,y) = max { A(x-i, y-j) | (i,j) ∈ B } Structuring element B = 3×3 all-ones matrix, 1 iteration
Dilation expands foreground (edge) pixels by 1 px in each direction, bridging small gaps (<3 px) in scratch contours without significantly altering scratch geometry.
Why Canny over Otsu? Scratches are linear, high-gradient features — well-suited to edge magnitude thresholding. Otsu performs global intensity binarisation, which is more effective for blob-type defects (rust patches, pitting) than for thin linear discontinuities.
4.4

Feature Extraction — 4D Vector

Four handcrafted scalar features are extracted per image, producing a compact 4-dimensional feature vector. Each feature is mathematically motivated by a distinct property of scratch vs. good surfaces.

Feature 1

Edge Density

Fraction of edge pixels after Canny + dilation. Scratched surfaces produce significantly more edges than smooth good surfaces.

Feature 2

Max Aspect Ratio

Maximum length-to-width ratio of connected edge contours. Scratches are elongated; noise blobs are compact.

Feature 3

GLCM Contrast

Second-order texture statistic measuring local intensity variation. High contrast ↔ abrupt surface discontinuities typical of scratches.

Feature 4

GLCM Homogeneity

Measures smoothness of the GLCM. High homogeneity ↔ uniform textures (good surface). Low homogeneity ↔ heterogeneous scratched areas.

Feature 1 — Edge Density
edge_density = (# non-zero pixels in dilated edge map) / (total pixels) = ||E||₀ / (H × W) where E ∈ {0,255}^(H×W) is the Canny+dilated binary edge map, H = W = 200 (fixed resize)
Range: [0, 1]. Typical good surface: <0.05. Typical scratch: 0.08–0.35. Known outlier scratches_74: 0.0014 (faint scratch not resolved by Canny).
Feature 2 — Max Aspect Ratio
For each connected contour C_i in the edge map: bounding_rect(C_i) → (w_i, h_i) aspect_ratio_i = max(w_i, h_i) / (min(w_i, h_i) + ε) max_aspect_ratio = max { aspect_ratio_i | i = 1 … N } ε = 1e-5 (prevents division by zero for degenerate contours)
A long straight scratch produces a bounding box with large aspect ratio (e.g., 8–25×). Compact noise blobs produce ratios near 1.
Feature 3 — GLCM Contrast
GLCM P(i,j) = joint probability of pixel pairs at offset (d=1, θ=0°) Contrast = Σ_i Σ_j (i − j)² · P(i,j) Normalised: P(i,j) = count(i,j) / Σ count(i,j)
High contrast indicates large local intensity differences — characteristic of scratch edges where dark groove meets bright metal surface. Computed via skimage.feature.graycomatrix + graycoprops.
Feature 4 — GLCM Homogeneity (Inverse Difference Moment)
Homogeneity = Σ_i Σ_j P(i,j) / (1 + |i − j|) Range: (0, 1]. Maximum value (=1) when all GLCM mass is on the diagonal, i.e. all co-occurring pixel pairs have equal intensity → perfectly smooth surface.
Good (smooth) surfaces score near 1. Defective surfaces score lower due to abrupt intensity transitions at scratch boundaries.
# Feature extraction — locked pipeline
from skimage.feature import graycomatrix, graycoprops

# 1. Edge density
edge_density = np.count_nonzero(dilated) / (200 * 200)

# 2. Max aspect ratio
contours, _ = cv2.findContours(dilated, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)
max_ar = 1.0
for cnt in contours:
    x, y, w, h = cv2.boundingRect(cnt)
    ar = max(w, h) / (min(w, h) + 1e-5)
    max_ar = max(max_ar, ar)

# 3 & 4. GLCM contrast and homogeneity (d=1, θ=0°)
glcm = graycomatrix(img, distances=[1], angles=[0], normed=True)
contrast    = graycoprops(glcm, 'contrast')[0,0]
homogeneity = graycoprops(glcm, 'homogeneity')[0,0]

features = [edge_density, max_ar, contrast, homogeneity]
4.5

Classification — StandardScaler + SVM

The 4D feature vector is standardised then classified by a Support Vector Machine. SVM was selected over the PCA/LDA/NearestCentroid design proposed in the architecture draft due to superior performance on this dataset's class imbalance (74 Good vs 240 Defective).

01

StandardScaler

Zero-mean, unit-variance normalisation of each feature dimension — required because edge_density (∈ [0,1]) and GLCM contrast (range can reach 100+) operate on very different scales.

Z-score Standardisation
z_k = (x_k − μ_k) / σ_k μ_k = mean of feature k over training set σ_k = std deviation of feature k over training set
02

Support Vector Machine (SVM)

The SVM finds a maximum-margin hyperplane in the standardised feature space that separates Good from Defective samples.

SVM Primal Optimisation Problem
minimise ½ ||w||² + C · Σ_i ξ_i subject to y_i (w·x_i + b) ≥ 1 − ξ_i ∀ i ξ_i ≥ 0 w = weight vector (defines separating hyperplane) b = bias term ξ_i = slack variables (allow soft-margin misclassification) C = regularisation constant (controls margin vs misclassification trade-off) y_i ∈ {−1, +1} (Good=0 → −1, Defective=1 → +1)
RBF Kernel (if non-linear boundaries needed)
K(x_i, x_j) = exp(−γ · ||x_i − x_j||²) γ controls kernel width — smaller γ → smoother decision boundary Decision: sign(Σ_i α_i y_i K(x_i, x) + b)
With only 4 well-engineered features, a linear or RBF kernel SVM generalises well without overfitting. predict_proba() (Platt scaling) converts SVM scores to confidence percentages in the FastAPI response.
03

Output

Binary class label: Good (0) or Defective/Scratch (1), plus a confidence score derived from Platt-scaled SVM probabilities. Served via FastAPI at /predict.

4.7

Known Pipeline Limitation

scratches_74.jpg — misclassified as Good (Class 0)

edge_density = 0.0014, max_aspect_ratio = 1.29. The scratch on this image is faint and low-contrast — Canny with T_low=10 was unable to detect sufficient edge pixels. The resulting feature vector resembles a good surface, causing the SVM to output the wrong class.

Root cause: Edge-based feature extraction is fundamentally limited for scratches with near-zero contrast gradient (e.g., very shallow or partially polished scratches).

Future work: Add LBP histogram or Gabor filter response features that capture texture-level anomalies independent of edge strength.
