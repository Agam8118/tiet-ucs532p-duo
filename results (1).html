Chapter 5 · Implementation & Experimental Results

Dataset & Results

Trained on 541 images, validated on 120 held-out images (60 scratch, 60 patch). SVM with 16-dimensional dual-branch feature vector achieves ~94% macro F1-score with balanced performance across both classes.

5.1

Dataset Description

Derived from the NEU Surface Defect Dataset, supplemented with web-sourced images for domain diversity. All images normalized to 128×128 grayscale with Histogram Equalization before any feature is extracted. The validation set is strictly held out — never used during training or PCA fitting.

The training set is balanced (240 images per defect class). The 61 clean images serve as a negative class during training to prevent the classifier from treating all surfaces as defective. Real-world supplementary images increase domain diversity and test the Histogram Equalization standardization against varying lighting and camera conditions.

The classifier achieves near-perfect separation between scratch and patch classes. The Hough line count alone provides strong discriminative power for scratch detection — scratch images consistently produce count > 5 while patch images return ≈ 0.

The PCA-compressed LBP features successfully capture the stochastic texture patterns of patch defects. When the SVM decision boundary is projected onto the two most discriminative PCA components, clear cluster separation is visible with a well-defined margin.

7.1

Challenges & Resolutions

01

Domain gap between NEU laboratory images and real-world Google images

Developed the Standardization Pipeline with Histogram Equalization to force all images to the same intensity manifold, measured as reduction in intra-class KL divergence across 20 sampled image pairs.

02

High dimensionality of raw LBP histogram (256 dims) relative to training set size

Applied selective PCA compression to the LBP branch only, retaining 95% variance in ~15 components. PCA fitted on training data only to prevent data leakage from validation.

03

Hough Transform producing false line detections on textured patch surfaces

Tuned minimum vote threshold to 80 and minimum line length to 30 px to suppress spurious lines from texture noise, validated by examining Hough_Line_Count distributions on held-out validation images.

04

Streamlit Cloud deployment failure — numpy version incompatibility with Python 3.13

Switched from exact version pinning (numpy==2.4.4) to minimum-version pinning (numpy>=1.26.0) in requirements.txt for compatibility with Streamlit Cloud's managed Python 3.13 environment.

05

opencv-python causing bootstrap failure on headless server environment

Replaced opencv-python with opencv-python-headless in requirements.txt for server-compatible deployment without a display system.

6.4

Future Work

Multi-Class Extension

Cover all six NEU defect classes (rolled-in scale, crazing, pitting, inclusion, patches, scratches) by adding branches or multi-class SVM.

Real-Time Camera Feed

Integrate OpenCV's VideoCapture for live webcam frames from an overhead industrial camera — inline inspection on rolling mill production lines.

Deep Learning Comparison

Controlled comparison of MobileNetV3 or EfficientNet-Lite against the classical pipeline on accuracy, inference latency, and hardware requirements.

Severity Quantification

Estimate defect severity using contour area and line density metrics to support graded quality control decisions beyond binary classification.

Edge Deployment

Package as a Docker container optimized for Raspberry Pi 5, enabling self-contained installation at inspection stations without a networked server.

LBP + HOG Fusion

Extend Branch B with HOG descriptors for gradient-based texture representation, potentially improving discriminative power on low-contrast surfaces.
