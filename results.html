Dataset Overview

Binary classification dataset: Good (No-Defect) vs Defective (Scratch). Class imbalance reflects real-world production conditions — defective parts are significantly more common in inspection batches.

Class 0 — Good
74

No-Defect (Self-collected)

Clean steel surface images captured using the same camera setup as the defective samples. Manually verified — ambiguous surfaces discarded.

Share of dataset23.6%
Class 1 — Defective
240

Scratch (NEU Dataset)

Linear scratch defects from the NEU Surface Defect Dataset — publicly available benchmark of real industrial steel surface images.

Share of dataset76.4%
Why self-collect the Good class? The NEU dataset contains only defective samples — no defect-free reference images. Mixing an unrelated public normal-class dataset would introduce domain mismatch. Self-collected images from the same imaging conditions ensure the classifier learns the correct surface texture of this workshop's components.

Known Limitation & Future Work

Pipeline limitation — faint / low-contrast scratches

The edge-based feature pipeline cannot reliably detect scratches with near-zero intensity gradient. scratches_74.jpg is the documented example: edge_density = 0.0014, max_aspect_ratio = 1.29 — values indistinguishable from a smooth good surface. Canny with T_low=10 found almost no edges. Result: misclassified as Good.

This is a fundamental limitation of Canny-based feature extraction for shallow or partially polished scratches that do not produce strong intensity discontinuities.

Proposed future improvements:

  • LBP histogram features — Local Binary Patterns capture micro-texture anomalies independent of edge strength. A faint scratch still disrupts the local texture pattern even when Canny misses it.
  • Gabor filter responses — Multi-orientation Gabor bank captures directional texture energy at the scratch orientation, robust to low contrast.
  • CLAHE preprocessing — Adaptive histogram equalisation before Canny could amplify faint scratches enough for edge detection to catch them.
  • Data augmentation — Synthetic faint-scratch augmentation to give the SVM examples of this failure mode during training.
