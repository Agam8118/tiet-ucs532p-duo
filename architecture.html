Chapter 4 · Design Specifications

System Architecture

A five-phase sequential pipeline with two parallel feature extraction branches — designed to physically separate geometric and textural defect signals before they reach the SVM classifier.

4.1

Five-Phase Pipeline

Every image passes through five sequential phases from raw input to final classification output. The dual-branch split occurs in Phase 2.

Phase 1
Standardization Pipeline
Grayscale conversion → 128×128 resize → Histogram Equalization. Forces all inputs to the same mathematical intensity manifold regardless of source (NEU lab vs. real-world factory/web images).
Phase 2A
Branch A — Geometric Analysis (Scratch detection)
Canny edge detection (low=50, high=150) → Probabilistic Hough Transform (min_votes=80, min_len=30px, max_gap=10px). Output: one integer — Hough_Line_Count. Scratch images consistently yield count > 5; patch images ≈ 0.
Phase 2B
Branch B — Textural Analysis (Patch detection)
Local Binary Patterns (P=8 neighbors, R=1, uniform method). For each pixel, a binary code is generated by thresholding circular neighbors against center intensity. Summarized as a 256-bin normalized histogram capturing micro-texture frequency distribution.
Phase 3
PCA Compression (Texture branch only)
PCA applied exclusively to the 256-dimensional LBP vector, retaining 95% variance in ~15 principal components. The Hough line count is preserved as a native scalar — it is not compressed. Final feature vector: [Hough_Count ‖ PCA_1 … PCA_15] = 16 dimensions.
Phase 4
CSV Dataset Generation
Each image stored as a row: Hough_Line_Count, PCA_1 … PCA_15, Target_Label (0=Scratch, 1=Patch). Output: features.csv with 541 training rows + 120 validation rows.
Phase 5
SVM Classification
StandardScaler normalizes the 16-dimensional input. RBF-kernel SVC (C=1.0, gamma='scale', class_weight='balanced', probability=True) classifies the surface. Output: binary label + per-class confidence score.
4.2

Dual-Branch Detail

Each branch is independently optimized for its target defect type — the key architectural novelty over monolithic feature concatenation.

Branch A · Geometric

Hough Line Count

Targets the linear geometry of scratch defects. Scratch images produce Hough_Line_Count > 5 consistently; smooth or patchy textures return ≈ 0.

Branch B · Textural

LBP + PCA Histogram

Targets the stochastic micro-texture of patch defects. LBP codes pixels by their local binary neighborhood, summarized as a 256-bin histogram compressed by PCA.
