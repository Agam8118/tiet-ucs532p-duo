System Architecture

Modular Pipeline Architecture

Five-stage classical CV pipeline terminating in a StandardScaler + SVM classifier. No GPU. No deep learning. CPU inference under 50 ms.

01

Design Principles

Modularity

Each stage has a defined input/output contract. Preprocessing, feature extraction, and classifier can be tuned independently.

Interpretability

Every prediction is traceable to four scalar feature values. No black-box layers — suitable for certified quality control environments.

CPU-Native

All operations — from Canny edge detection to SVM inference — run on standard CPUs. No GPU dependencies.

Low-Data Regime

Designed for ~300 samples. A 4D feature vector + StandardScaler prevents overfitting without requiring PCA dimensionality reduction.

02

Full Pipeline Architecture

S1 ↓

Image Acquisition

Standard RGB camera image of a metal surface. Both self-collected good surfaces and NEU dataset scratch images are accepted. Images do not require controlled laboratory conditions.

RGB Input NEU Dataset Self-collected Any resolution
S2 ↓

Preprocessing

Grayscale conversion → resize to 200×200 px → median blur (kernel=5) for salt-and-pepper noise suppression. Parameters are locked and must not be changed.

Grayscale Resize 200×200 Median Blur k=5
S3 ↓

Defect Segmentation

Canny edge detection with locked thresholds (T_low=10, T_high=70) followed by morphological dilation (3×3 kernel, 1 iteration). Produces a binary edge map isolating scratch-like linear discontinuities.

Canny (10, 70) Dilate 3×3 Binary edge map
S4 ↓

Feature Extraction

Four handcrafted scalar features per image: edge density (fraction of edge pixels), max aspect ratio of edge contours (scratch elongation), GLCM contrast (local intensity variation), and GLCM homogeneity (surface smoothness). Computed at d=1, θ=0°.

Edge Density Max Aspect Ratio GLCM Contrast GLCM Homogeneity 4D vector
S5 ↓

StandardScaler + SVM Classification

The 4D feature vector is z-score standardised (zero mean, unit variance per feature) and passed to a fitted SVM. Platt scaling (predict_proba) converts decision scores to confidence percentages. Trained artifacts: svm_model.pkl, scaler.pkl.

StandardScaler SVC (Platt scaling) svm_model.pkl scaler.pkl 98% accuracy
S6

FastAPI Deployment — app.py

The trained model is served via a FastAPI server at /predict. Accepts multipart image upload, runs the full preprocessing + feature + SVM pipeline, returns JSON with filename, status, and confidence. Interactive Swagger UI at localhost:8000/docs.

FastAPI uvicorn /predict JSON response

Data Flow Specifications

StageFormatNotes
Input RGB image, any resolution JPEG, PNG accepted by FastAPI endpoint
After Grayscale + Resize uint8 grayscale, 200×200 px Pixel values [0, 255]
After Median Blur uint8 grayscale, 200×200 px Salt-and-pepper noise suppressed
After Canny + Dilate Binary edge map, 200×200 px Values ∈ {0, 255} — edge pixels only
After Feature Extraction 1D float array, 4 dimensions [edge_density, max_aspect_ratio, contrast, homogeneity]
After StandardScaler 1D float array, 4 dimensions Zero-mean, unit-variance per feature
Output Integer label ∈ {0, 1} + float confidence ∈ [0,1] 0 = Good, 1 = Defective (Scratch) 
# Full inference pipeline (predict.py / app.py)
img     = cv2.imread(path, cv2.IMREAD_GRAYSCALE)
img     = cv2.resize(img, (200, 200))
img     = cv2.medianBlur(img, 5)
edges   = cv2.Canny(img, 10, 70)
dilated = cv2.dilate(edges, np.ones((3,3),np.uint8), iterations=1)

# 4D feature vector
features = extract_features(img, dilated)   # [ed, ar, contrast, homog]

# SVM inference
feat_scaled = scaler.transform([features])
label = model.predict(feat_scaled)[0]          # 0 or 1
conf  = model.predict_proba(feat_scaled)[0].max() * 100
04

Classifier Comparison

Multiple classifiers were considered. SVM was selected for its strong performance on small, imbalanced datasets with well-engineered low-dimensional feature vectors.

SVM (RBF / Linear) ✓ Deployed

98% Accuracy

Max-margin classifier ideal for small, high-quality feature sets. Platt scaling provides calibrated confidence scores. Handles class imbalance (74 vs 240) robustly.

LDA + Nearest Centroid

Architecture Plan

Original design target. Works well with PCA-reduced high-D features. Replaced by SVM after empirical testing showed higher accuracy on this 4D feature set.

Random Forest

Baseline Ensemble

Non-linear ensemble with feature importance rankings. Could quantify which of the 4 features contributes most to classification — useful for future feature analysis.

k-NN (k=5)

Simple Baseline

Majority vote among 5 nearest neighbours. Sensitive to class imbalance (240 vs 74 samples) without distance weighting — included only as a sanity-check baseline.
