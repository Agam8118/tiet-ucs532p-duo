Chapter 3 & 5 · Methodology & Implementation

Methodology Adopted

Experimental investigative approach — independent variables are feature extraction configurations and SVM hyperparameters. Dependent variable is macro F1-score on the held-out 120-image validation set.

3.2

Proposed Solution — Five Phases

Phase 1

Standardization Pipeline

Grayscale → 128×128 resize → Histogram Equalization. Forces all images to the same intensity manifold regardless of source.

Phase 2

Dual-Branch Extraction

Branch A: Canny + Hough → Hough_Line_Count (scalar). Branch B: LBP → 256-bin normalized histogram.

Phase 3

PCA Compression

PCA exclusively on 256-dim LBP vector, retaining 95% variance (~15 components). Hough scalar preserved intact. Final vector: 16D.

Phase 4 & 5

CSV Generation + SVM

Features written to features.csv. StandardScaler + RBF-SVM (GridSearchCV, 5-fold stratified CV) trained on 541 images.

5.2.1

Pseudocode — Standardization Pipeline

standardize.py

FUNCTION standardize(image_path): img ← cv2.imread(image_path) gray ← cv2.cvtColor(img, BGR2GRAY) resized ← cv2.resize(gray, (128, 128)) # bilinear interpolation eq ← cv2.equalizeHist(resized) # T(r) = (L−1)·CDF(r), L=256 RETURN eq # 128×128 domain-normalised image

Histogram Equalization remaps intensities so the output CDF is approximately uniform — compressing dark factory images and bright Google images into the same intensity range as the NEU laboratory images.

5.2.2

Pseudocode — Branch A · Geometric

branch_a.py — Canny + Hough Transform

FUNCTION extract_branch_a(equalized_img): edges ← cv2.Canny(equalized_img, low=60, high=140) lines ← cv2.HoughLinesP( edges, rho=1, theta=π/180, threshold=80, minLineLength=30, maxLineGap=10 ) IF lines is None: hough_count ← 0 ELSE: hough_count ← len(lines) # scalar integer RETURN hough_count

The Probabilistic Hough Transform maps edge points from Cartesian space to polar parameter space (ρ, θ). Only lines above the minimum vote threshold (80) and minimum length (30 px) are counted, suppressing false detections from textured patch surfaces.

5.2.3

Pseudocode — Branch B · Textural

branch_b.py — Local Binary Patterns

FUNCTION extract_branch_b(equalized_img): # LBP code for pixel (xc, yc): # LBP(xc,yc) = Σₚ s(Iₚ − Ic) × 2ᵖ where s(x)=1 if x≥0 else 0 lbp_map ← local_binary_pattern( equalized_img, P=8, R=1, method='uniform' # 59 uniform patterns ) hist ← histogram(lbp_map, bins=256, range=(0, 256)) hist ← hist / sum(hist) # normalize to unit sum RETURN hist # 256-dimensional vector

Uniform patterns (at most 2 bitwise transitions in the binary string) account for most naturally occurring textures. There are 59 uniform patterns out of 256 possible LBP codes.

5.2.4

Pseudocode — Selective PCA Compression

PCA applied to Branch B only

# TRAINING PHASE — fit on training LBP vectors only (no data leakage) pca ← PCA(n_components=0.95) # retain 95% variance pca.fit(X_train_lbp_histograms) # k chosen s.t. Σλᵢ/Σλ ≥ 0.95; k≈15 # FEATURE COMBINATION — at inference time FUNCTION combine_features(hough_count, lbp_hist): pca_texture ← pca.transform([lbp_hist])[0] # ~15 dims feature_vector ← [hough_count] + list(pca_texture) # 16 dims total RETURN feature_vector

Novelty — Why selective PCA?

Applying PCA globally would dilute the Hough line count by mixing it with texture variance. The Hough scalar has direct physical meaning (number of detected linear scratches) and its discriminative power is preserved only if it reaches the SVM in its native integer form. This is an underexplored design pattern in the surface defect detection literature.

SVM Hyperparameters

Optimized via GridSearchCV on 5-fold stratified cross-validation over the training set.

HyperparameterValueRationale
kernelrbfHandles non-linear separability in the 16-dimensional feature space
C1.0Balances margin maximization and training error — empirically optimal on this dataset
